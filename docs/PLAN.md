# Copia — plan

Remplaçant personnel de CopyClip (FIPLAB), natif Swift/SwiftUI + AppKit, sans dépendance externe,
optimisé Apple Silicon / macOS 26+.

## Ce qu'on garde de CopyClip (analyse REA de la v1.9.86)

| CopyClip | Copia |
|---|---|
| Icône dans la barre des menus, liste des clips | ✅ panneau flottant (non activant, garde le focus de l'app en cours) |
| « Remember » / « Display » (80 / 20) | ✅ 300 conservées (jusqu'à 5 000), 20 affichées |
| Raccourci global (MASShortcut) | ✅ raccourci Carbon natif, enregistreur dans les réglages (⌥⌘V par défaut) |
| Coller au clic (AppleScript `keystroke "v"`) | ✅ CGEvent ⌘V direct (plus rapide, pas d'AppleScript) |
| Exceptions (apps en liste noire) | ✅ + respect automatique des marqueurs nspasteboard.org (mots de passe, transitoires) |
| Démarrage à l'ouverture de session | ✅ SMAppService |
| Effacer / supprimer des clips | ✅ + épingler |
| Base Core Data SQLite | ✅ SQLite3 direct (WAL, écritures en tâche de fond) + **import de l'historique CopyClip** |
| Pubs / télémétrie FIPLAB (`api.fiplabcdn.com`) | ❌ supprimé, zéro réseau |

## Nouveautés

1. **Recherche floue en tête de panneau** : tape directement, sans accents ni casse, mots dans le désordre,
   tolère les fautes de frappe (Damerau-Levenshtein), surlignage des correspondances, extrait autour du match.
   Elle porte sur tout l'historique, pas seulement sur les 20 entrées affichées.
2. **Dictée intelligente** (activée par défaut, désactivable) :
   - fusion des doublons exacts : un même texte n'existe qu'une fois et remonte en haut ;
   - détection de la restauration A → B → A (VoiceInk, superwhisper…) via les marqueurs
     `org.nspasteboard.source` / `AutoGeneratedType` **et** via le timing (fenêtre réglable) ;
   - l'ancien presse-papier restauré ne remonte pas (option) et la dictée est badgée « Dictée » ;
   - compteurs (doublons fusionnés, restaurations ignorées).
3. **Ouverture au curseur de texte** (Accessibilité), avec repli sur la souris, le centre de l'écran ou la barre des menus.
4. Clavier complet : ↑↓, ↩ coller, ⌘↩ copier seulement, ⌘1…9, ⌘P épingler, ⌘⌫ supprimer, ⎋.
5. Réglages premium : barre latérale façon Réglages Système, pages animées, statistiques, mémoire utilisée.
6. Rétention par âge (7/30/90/365 jours), lignes d'aperçu, style givré ou Liquid Glass.

## Énergie / performance

- Seul `changeCount` est lu (appel très léger), avec un timer à tolérance qui permet à macOS de regrouper les réveils.
- Fréquence adaptative (Économie 0,6 s / Équilibré 0,3 s / Instantané 0,15 s), ralentie après 2 min d'inactivité.
- Arrêt complet pendant la veille, l'écran éteint ou la session verrouillée.
- Interface SwiftUI démontée quand le panneau est fermé, ce qui évite tout rendu en arrière-plan.
- Recherche hors du thread principal, clés de recherche normalisées en cache, icônes d'apps en cache.
- SQLite en WAL, écritures asynchrones sur une file utilitaire. Binaire arm64 optimisé (-O, dead-strip).

## Phase 2 : images, fichiers, texte riche (v1.1, livrée le 2026-11-01)

- **Images et captures** : PNG/TIFF/JPEG/HEIC/GIF/WebP. Stockage HEIC qualité 90 % (ou original sans perte)
  dans `~/Library/Application Support/Copia/Blobs`, miniature 240 px, doublons détectés par hash exact des octets.
  Recollées dans leur format natif ; PNG et TIFF fournis à la demande (`NSPasteboardItemDataProvider`).
- **OCR Vision** (`RecognizeTextRequest`, fr + en) en arrière-plan, après l'encodage : le texte des captures est
  cherchable. Le 1er OCR après le lancement charge le modèle (jusqu'à ~30 s), les suivants < 1 s.
- **Fichiers du Finder** : recollés en tant que fichiers, ⌥↩ colle les chemins, badge « Introuvable », ⌘O / ⌘R.
- **Texte riche** (RTF, RTFD, HTML ≤ 8 Mo) : recollé avec sa mise en forme, ⌥↩ en texte brut (réglage pour inverser).
  Même hash que le texte brut, pour que la restauration VoiceInk reste reconnue.
- Filtres Tout / Texte / Images / Fichiers (⌘← ⌘→), aperçu ⌘Y adapté à chaque type, glisser-déposer vers d'autres apps.
- Plafond disque (1 Go par défaut) : les images les plus anciennes partent d'abord ; le texte riche ancien perd
  seulement sa mise en forme. Ménage des fichiers orphelins au lancement.
- Base v2 : colonne `meta` (JSON), migration automatique depuis la v1.
- Classement du presse-papier : logique pure `ContentClassifier`, testée (fichiers > image seule > texte riche > texte).
